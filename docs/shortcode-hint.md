# Справочник: спец-метки модулей Виты в контенте

Канонический источник текста подсказки. Этот же текст (компактная форма)
вшивается в шапку экспортного файла конструктора (`src/export/export.js`)
и в карточку «Вставка спец-меток из конструктора» документации темы
(`docs/index.html`, репозиторий `main_vita`).

Гейт синхронизации: уникальная строка ниже должна присутствовать во всех
трёх местах. Проверка: `python build/sync_to_theme.py check` (конструктор)
и `node docs/assets/check-docs-sync.js` (тема).

---

## Канонический текст (compact, одна строка)

VCC-SHORTCODE-HINT-v1: Спец-метки модулей Виты вставляйте текстовым блоком или через блок «HTML темы» — они переживают экспорт и импорт, а на витрине превращаются в живые блоки модулей. В палитре конструктора есть готовые блоки спец-меток с выбором ID из каталога магазина.

## Полный список меток

| Метка | Что выводит на витрине |
|---|---|
| `[vita_visual id=N]` | блок «Визуальные блоки» (слайдер / баннер / LookBook) |
| `[vita_all_in_one id=N]` | блок «Универсальные блоки товаров» |
| `[vita_extra_wall id=N]` | блок «Стена категорий, брендов и ссылок» |
| `[vita_faq id=N]` | группа FAQ (без `id` — все активные группы) |
| `[vita_form id=N]` | форма магазина |
| `[vita_news id=N]` | статья блога (без `id` — лента новостей) |
| `[vita_testimonial id=N]` | отзывы о магазине |
| `[vita_news_gallery id=N]` | галерея изображений из блога |
| `[vita_gallery id=N]` | галерея изображений модуля |
| `[vita_html]…[/vita_html]` | точечная вёрстка (теги и классы — только из контракта vcc) |

`N` — номер блока из списка соответствующего модуля в админке магазина.
Выключенный блок на витрине не показывается.

## Правила

1. Метка — обычный текст: вставляйте её текстовым блоком или в код-вид
   блока «HTML темы». Не вставляйте в визуальный (WYSIWYG) режим редактора.
2. В палитре конструктора (группа «Модули магазина») есть готовые блоки
   спец-меток с выбором ID из каталога магазина — они надёжнее ручного ввода.
3. Санитайзер темы при импорте пропускает текст метки без изменений —
   живой модуль подставляется движком темы уже на витрине.
4. Метку можно вкладывать в статью, в HTML-блок, в конструктор — вложенность
   до 5 уровней обрабатывается движком темы; зацикливание обрывается
   на 5-м проходе.
