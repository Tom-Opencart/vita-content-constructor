# Вита — Конструктор контента

Визуальный конструктор контента для темы **Вита** (OpenCart 3). Собирайте
описания товаров, статьи и посадочные страницы блоками — без знания HTML —
и переносите готовый контент в модуль **«Вита — Универсальные блоки контента»**.

Конструктор работает целиком в браузере (без бэкенда), и заточен под Виту:
предпросмотр и экспорт используют палитру и тёмную тему именно вашей темы.

**Онлайн (GitHub Pages):** [tom-opencart.github.io/vita-content-constructor](https://tom-opencart.github.io/vita-content-constructor/) — открыли и собираете, установка не нужна.

## Быстрый старт (для владельца магазина)

1. **Цветовая схема (необязательно, но рекомендуется).** При первом открытии
   конструктора появится окно «Как это работает»: скачайте пресет в админке
   (*Расширения → Вита → Дизайн и стили → «Экспорт пресета для Конструктора»*,
   тема 1.10.1+) и загрузите его в это окно — конструктор окрасится в цвета
   магазина, включая тёмную тему. Шаг можно пропустить — используется палитра
   Виты по умолчанию; файлы старого формата тоже принимаются.
2. **Соберите контент.** Полный редактор открыт сразу — под окном онбординга
   и после его закрытия. Добавляйте блоки из палитры слева или загрузите
   готовый макет там же в окне (обзор товара, статья, FAQ — файлы из
   `presets/layouts`). Вернуться к справке: кнопка с домиком в шапке.
3. **Перенесите в магазин.** Нажмите «Скачать» — получите файл
   `content-<имя>.html` — и загрузите его в модуль «Вита — Универсальные
   блоки контента» кнопкой «Импорт из Конструктора» (тема 1.10.1+): файл
   проверяется и очищается на сервере, опасная разметка не пройдёт.
   «Копировать HTML» — альтернатива для вставки в любой редактор.
4. **Выведите блок на странице.** Разместите модуль в макете или привяжите
   к селектору — стили подключатся автоматически в обоих случаях.

Блоки-шорткоды `[vita_faq]` и `[vita_form]` вставляют живые модули магазина
(FAQ-группы и формы): в файл они попадают как литеральный шорткод, а тема
заменяет его на витрине сама. Группы и формы выбираются из списка — пресет
магазина приносит каталог реальных модулей (названия и счётчики прямо из
админки); без пресета поле остаётся ручным вводом ID.

Стили подключать **не нужно**: тема Вита несёт их в поставке
(`vita-content-constructor.css`, контракт `vcc-v1`, тема 1.10.1+) и
подключает автоматически — импортированный контент одинаково выглядит
в светлой и тёмной теме. Кнопка «CSS» — только для нестандартных шаблонов.

> Для разработки: файл стилей в теме — точная копия `css/export.css`.
> Синхронизация: `python build/sync_to_theme.py sync`, проверка пары
> коммитов обоих репозиториев: `python build/sync_to_theme.py check`.

## Возможности

- 34 типа блоков в трёх группах:
  - **Блоки контента**: заголовки, текст (мини-markdown), списки, цитаты, врезки,
    табы, таблицы, картинки, оглавление.
  - **Лендинг-секции (0.7.0)**: обложка (Hero), бейджи доверия, преимущества,
    картинка + текст, шаги/таймлайн, цифры, отзывы, команда, документы, призыв,
    контакты, соцсети, чек-лист, разделитель, SEO-текст, тарифы, колонки,
    видео, логотипы партнёров — каждая секция с выбором фона, отступов,
    ширины и якоря.
  - **Модули магазина**: `[vita_faq]`, `[vita_form]`, `[vita_visual]`,
    `[vita_all_in_one]`, `[vita_extra_wall]`, `[vita_html]…[/vita_html]`.
    FAQ-аккордеоны — только живым шорткодом: вопросы и ответы ведутся в админке магазина.
- Предпросмотр в контексте магазина: мок шапки и подвала с некликабельными
  тестовыми данными, светлая и тёмная темы.
- Цвета блоков — только из палитры вашего магазина (токены темы), никаких
  случайных оттенков.
- Ссылки-соглашения OpenCart: `[текст](agree:ID)` открывает попап
  информационной статьи; кнопка-форма `[текст](form:ID)` открывает модалку
  формы магазина (0.7.0); акцент `==текст==` выделяет слова фирменным цветом.
- Автосохранение в браузере, отмена действий, экспорт/импорт проекта JSON.

## Для разработчика

```bash
python build/build.py   # собрать js/app.js из src/
```

Структура:

```
src/core/     токены vcc-v1, схема, markdown, реестр, store
src/blocks/   типы блоков
src/export/   экспорт HTML/CSS/JSON + импорт
src/ui/       интерфейс (онбординг, редактор, предпросмотр)
css/          app.css (интерфейс) + export.css (ЕДИНСТВЕННЫЙ источник экспортных стилей)
presets/      themes/ (пресеты палитры) + layouts/ (готовые макеты)
build/        сборщик
```

Контракты и правила для агентов — в [AGENTS.md](AGENTS.md).

## Публикация (GitHub Pages)

Сборка не нужна на сервере: `js/app.js` коммитится вместе с исходниками, Pages
раздаёт репозиторий как есть.

1. **Создайте ПУБЛИЧНЫЙ репозиторий** `vita-content-constructor` на GitHub
   (публичность обязательна: Pages для приватных репо требует платный план;
   публичная гигиена — см. `AGENTS.md`, в репо нет ничего от исходников темы).
2. **Запушьте main** (из папки репозитория):

   ```bash
   git remote add origin https://github.com/Tom-Opencart/vita-content-constructor.git
   git push -u origin main
   ```

   Сайт появится по адресу `https://tom-opencart.github.io/vita-content-constructor/`.
   Кнопка «Открыть конструктор» в теме и карточка в документации уже ведут
   на этот адрес (обновлено в теме 1.10.1+, сентябрь 2026).

3. **Включите Pages**: Settings → Pages → Source «Deploy from a branch» →
   Branch `main`, folder `/ (root)` → Save.
4. Через ~1 минуту конструктор живёт по адресу
   `https://tom-opencart.github.io/vita-content-constructor/`.
5. **Обновления**: каждый пуш в `main` пересобирает сайт автоматически
   (~1 минута). Правило то же, что в релизном репо темы: `js/app.js` уезжает
   В ТОМ ЖЕ коммите, что и правки `src/` — `python build/build.py` перед
   коммитом обязателен.

Замечания:

- Репозиторий НЕ содержит секретов и бэкенда — утечке при публичности
  подлежать нечему; правило гигиены (`AGENTS.md`) держит его таким.
- Единственная внешняя зависимость — FontAwesome 4 c CDN cdnjs (иконки
  интерфейса; на экспорт контента не влияет).
- Проверка после деплоя: открыть сайт в приватном окне, создать блок,
  скопировать HTML — кэш Pages агрессивен, проверяйте именно свежий деплой.
