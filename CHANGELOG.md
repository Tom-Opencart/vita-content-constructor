# Changelog

Все заметные изменения Вита — Конструктора контента.

## [0.10.3] — 2026-09-26

Запрос владельца: «в каждый блок практически на уровне настройки Конструктора
нужно дать возможность добавить кнопку. И потом эту кнопку отдельно изменить:
функционал — 1. Выбор фона, 2. Выбор размера, 3. Выбор функции при клике, итд итп».

Спецификация:

1. **Фабрика кнопок** (`vccButton()` в core/markdown.js) — единая точка рендера
   для ВСЕХ блоков: `<a class="vcc-btn vcc-btn--{bg} vcc-btn--{size}" href data-vcc-*>`;
   иконка — `data-vcc-icon` (рантайм темы подменяет на FA, контракт на data-атрибуте).
2. **Выбор фона** — `primary` (палитра) / `dark` (тёмная нейтральная #27272A) /
   `ghost` (контур) / `link` (текстовая, стрелка).
3. **Выбор размера** — `md` (44px, по умолчанию) / `sm` (36px) / `lg` (54px) /
   `full` (на всю ширину контейнера).
4. **Выбор действия при клике** — наследуется от существующих механизмов:
   ссылка (http/якорь/внутренняя), `form:ID` (модалка формы магазина —
   data-vcc-form, рантайм темы), `[text](form:ID)` в markdown остаётся как был.
5. **Иконка** — до/после текста, FA-имя без `fa-`.
6. **Поля блока** — «Кнопка» (вкладка-группа в конце формы каждого блока):
   текст, ссылка/действие, фон, размер, иконка; кнопка появляется при заполненном
   тексте (пустой текст = кнопки нет — прежний рендер блоков не меняется).
7. **Покрытие блоков** — text-группа (heading, paragraph, list, quote, alert,
   tabs, table, image, toc) + уже имевшие кнопки блоки (hero, media_text, cta,
   row, promo_card, key_card) переходят на фабрику без смены контракта классов.
8. **CSS** — модификаторы `vcc-btn--sm/lg/full/link`; вся стилизация на токенах;
   тёмная тема — существующие токены, новых цветов нет.

Сборка главной-витрины по референсу opencartforum.com.ru (том-модерн hero):

- **Hero: панель «карточка ключа + плитки»** (`visual: keycard`) — правая
  колонка обложки: `vcc-keycard` (мета-шапка, тёмное окно, сегменты с dim,
  чипы) + две сетки плиток `vcc-stats--boxed` (цифры) и `vcc-stats--strips`
  (лейбл над значением, полоска-акцент) на обёртке `.vcc-hero__panel`;
  сегменты значения — rows-editor как у key_card (чередование dim).
- **Hero: заголовок в верхнем регистре** (`title_upper`) —
  `.vcc-hero__title--upper` (uppercase, line-height 0.98).
- **Stats: стиль «lined»** — полоса с линиями-разделителями между плитками
  (`vcc-stats--lined`), референс stats-strip донора; на <768px — 2 колонки.
- **Alert: до двух кнопок** под текстом (`.vcc-alert__actions`, ghost) —
  референс warning-alert донора («Подробнее» / «Проверить сайт»).
- Стили аддитивны, только существующие классы + `vcc-hero__panel` /
  `vcc-hero__tiles` / `vcc-alert__actions` / `vcc-hero__title--upper`;
  экспортные классы контракта не менялись.

## [0.10.2] — 2026-09-26

Выполнено по замечаниям сверки с эталоном:

- **Списки в стиле plain-list референса**: без диск-буллетов — квадратная
  точка-акцент 8×8 слева, строка 14px приглушённым текстом, жирные фрагменты —
  основным цветом; нумерованные — акцентные цифры с точкой
  (`vcc-list--ordered`).
- **Убраны навязчивые hover-эффекты карточек** (сдвиг + жёсткая тень +
  тёмный бордер на features/pains/updates/reviews и др.) — карточки статичны,
  как у референса-донора; остался hover только у кнопок и ссылок.

План v2, утверждённый в обсуждении по двум референсным страницам
opencartforum.com.ru («OpenCart Клуб» и «Быстрый старт», Tom Modern).
Выполнено:

1. **Кикер/аннотация мелким шрифтом** — у hero и блока «Ряд» поле над H1
   (голый uppercase-текст `.vcc-hero__kicker` без плашки и маркера).
2. **Размер заголовка** — селектор 42/56/64/76px у hero и «Ряда»
   (`.vcc-hero__title--md/lg/xl`), у заголовков секций 34/40/48
   (`.vcc-section__title--md/lg`); на <768px — свои мобильные значения.
3. **Живой пример при редактировании** — у ВСЕХ блоков: под формой рендер
   текущего блока (`.vcc-live`), мгновенная перерисовка по селекторам и
   секционным полям; структурные переключатели (visual/left_mode/right_card/
   copy/body) пересобирают форму целиком.
4. **Блок «Ряд» (`row`)** — двухколоночная композиция: слева текстовый
   стек (кикер, заголовок, текст, до 2 кнопок, note) ИЛИ promo_card, справа
   выбираемая карточка (key_card / код-окно / метрики / без); пропорция
   «текст шире (2:1)» или «поровну»; на <992px — колонка.
5. **promo_card** — промо-карточка (референс «UNISHOP2»): опциональная
   шапка-полоса с логотипом, бейдж-стикер в accent-стиле (рамка + текст
   цветом акцента), выделенный uppercase-заголовок, промо-текст (markdown),
   кнопка вызова (ссылка/form:ID, стиль dark/primary/ghost); работает и
   самостоятельной секцией, и левым слотом «Ряда».
6. **key_card → промо-купон** — вид тела «тёмное окно» (`body: window`,
   сине-тёмный градиент референса) + пунктирная линия с белыми узлами-точками
   по краям; бейдж, mono-сегменты и чипы — прежние.
7. **Универсальная копи-кнопка** — в key_card, promo_card и «Ряде»:
   текст кнопки, «что копировать» (пусто → авто-источник: неприглушённые
   сегменты / текст кода). Рендер `<button class="vcc-copybtn"
   data-vcc-copy="…">` (контракт на data-атрибуте, `<button>` и data-vcc-*
   уже в whitelist санитайзера темы — поверхность безопасности не расширена);
   обработчик — делегированный клик в common.js темы (Clipboard API +
   execCommand-фолбэк), фидбек «Скопировано ✓» 2с; тёмная тема — токены.
8. **stats: два новых вида** — `boxed` (рамочные карточки, число 28px) и
   `strips` (полоска 32×5 акцента + uppercase-лейбл + значение 15px).
9. **Кнопка dark** — стиль `dark` для btn1 hero/«Ряда»/promo_card:
   `var(--vita-btn-dark, #27272A)` — тёмная нейтральная референса, не
   привязанная к палитре; hover — `--vita-btn-dark-hover, #3F3F46`.
10. **Линия над строкой доверия** — чекбокс в hero (`note_lined`):
    1px-разделитель `.vcc-hero__note--lined`.

Критерий приёмки: обе референсные страницы собираются поэлементно 1:1;
витрина на стенде; тёмная тема и 390px — без регрессий.

## [0.10.1] — 2026-09-26

- **Тема: глобальное подключение стилей конструктора** (парный релиз):
  `vita-content-constructor.css` подключается одной точкой в `before_header`
  темы на всех страницах витрины (HTML-модуль, статьи блога, описания товаров
  и категорий, information) — пер-контроллерные `addStyle` убраны; в режиме
  «Слияние CSS» файл попадает в общий минифицированный бандл.

- **Новый блок «Спецификация»** (`spec_list`, референс spec-list): строки
  «лейбл → значение» с uppercase-подписями, разделителями и фикс-колонкой
  лейблов (200px, на мобиле — стек). В значениях работает markdown, включая
  `[кнопку формы](form:ID)`.
- **Новый блок «Сравнение»** (`comparison`, референс comparison): пары
  «альтернатива / наше решение»; строка с флагом «наше решение» подсвечивается
  рамкой-акцентом и подложкой токена; опциональное примечание под таблицей.
- **Новый блок «Типичные проблемы»** (`pain_points`, референс pain-points):
  сетка рамочных карточек «болей» (2–4 колонки) с квадратным маркером цвета
  опасности у заголовка и левой чертой; hover — жёсткая тень.
- **Новый блок «Обновления»** (`updates_grid`, референс updates-grid): сетка
  article-рамок «что нового» с опциональной меткой (обычная и зелёная
  акцентная), 2–4 колонки.
- **Hero: панель-визуал с метриками** (`visual: metrics`, референс
  hero-visual): рамочный блок справа — статус-лейбл, строка пути и до 4
  метрик «значение + подпись»; раскладка flex-парой от 992px, колонка ниже;
  на зелёной секции панель полупрозрачная поверх фона.
- **Редактор: зависимые поля** (`depends: 'key:value'`) — поля панели-визуала
  показываются только у соответствующего вида.

## [0.10.0] — 2026-09-25

- **Рестайл всех блоков по правилу Tom Modern** (tom-modern-html-style-rule):
  бокс-надзаголовок (eyebrow) с квадратным маркером палитры, акцентная черта
  над заголовками секций (в центрированных — центрируется), рамочные карточки
  с нулевыми радиусами и жёсткой offset-тенью при наведении (преимущества,
  шаги, отзывы, команда, тарифы), квадратные бейджи-иконки, uppercase-лейблы
  (табы, роли, метки тарифов, авторы цитат), строки-спецификации в контактах,
  редакторская цитата с левой чертой, острые кнопки с контрастным hover
  (цвет текста фиксируется вместе с фоном — текст больше не исчезает),
  острые углы медиа и меток «До/После». Всё на токенах `--mp-*` — тёмная
  тема следует автоматически.
- **Новый блок «Карточка ключа»** (`key_card`): премиальный артефакт для
  лицензий, промокодов и сертификатов — тёмная карточка с диагональным
  градиентом (инверсия токенов: тёмная в светлой теме, светлая в тёмной),
  однократный sheen-блик (уважает `prefers-reduced-motion`), янтарная метка
  (`--mp-star-color`), моноширинное значение из сегментов с приглушением,
  перфорация и чипы с иконками через `data-vcc-icon`.
- **Новый блок «Код-окно»** (`code_window`): окно редактора с «светофором»
  из badge-токенов, mono-заголовком файла и подсветкой синтаксиса
  (`keyword/function/string/number/property/comment/punctuation`) на токенах
  палитры. Переносы строк — `<br>` в разметке: строки не склеиваются даже
  при минификации HTML темы; тело окна изолировано от стилей витрины
  для голых `pre`/`code`.
- **Оглавление: два режима отображения**: «Сверху (в контенте)» — как раньше,
  и «Фиксированная левая колонка» — sticky-панель 240px по образцу
  `vita-news-toc` темы (обёртку строит рантайм темы; на экранах <992px
  колонка схлопывается наверх).
- Иконки чипов внутри карточки ключа — компактные (14px, прозрачный фон):
  базовый стиль бейджа `.vcc-icon` больше не ломает вид чипа.

- Каталог переживает перезагрузку браузера (localStorage).

## [0.2.0] — 2026-09-20

Синхронизация с темой Vita 1.10.1: конструктор и модуль «Универсальные блоки контента» работают как единая система.

- **Блоки-шорткоды `[vita_faq]` и `[vita_form]`** (новая группа «Модули магазина»): живые модули магазина прямо в контенте. В редакторе — некликабельный мок-плейсхолдер с бейджем; в экспорт идёт только литеральный шорткод в обёртке `vcc-shortcode` — движок темы заменяет его на витрине, моки в файл и буфер не попадают никогда. FAQ: ID группы (0 — все активные) и опциональный заголовок; Форма: ID обязателен, без него блок не экспортируется.
- **Палитра магазина по контракту 1.10.1**: принимается каноничный экспорт кнопки «Экспорт пресета для Конструктора» (`type: vita-theme-preset`, поле `name`) и, для совместимости, ранние экспорты (`schema: vita-theme-preset-v1`).
- **Галерея макетов** на первом экране: «Статья-гид», «Страница FAQ», «Обзор товара» — превью карточек рендерятся настоящим экспортным рендером (WYSIWYG), автоматически перекрашиваются загруженной палитрой магазина.
- **Публикация**: репозиторий открыт (`Tom-Opencart/vita-content-constructor`), сайт живёт на GitHub Pages; кнопка «Открыть конструктор» в теме и документация ведут сюда.
- Санитизация на стороне темы проверена против реального экспорта: обёртка, литеральные шорткоды и `data-vcc-*` проходят без потерь, `onclick`/`javascript:`/`<script>` вырезаются.
- Мелкие правки, улучшения и исправления.
