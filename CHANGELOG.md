# Changelog

Все заметные изменения Вита — Конструктора контента.

## [0.7.4] — 2026-09-20

- **Чек-лист перед экспортом**: если в проекте нет ни одного блока группы «Модули магазина», при нажатии «Скачать» появляется мягкое напоминание (инфо-тост, экспорт не блокируется): живые модули — слайдер, FAQ, форма, товары — добавляются блоками из палитры. Предупреждения о незаполненных формах работают как раньше и показываются отдельным тостом.

## [0.7.3] — 2026-09-20

- **Подсказка о спец-метках вшита в экспортный файл**: каждый скачанный HTML теперь несёт комментарий с каноническим текстом (виден при открытии файла в любом редакторе; при импорте в модуль санитайзер темы снимает комментарий — контент не замусоривается).
- **Канонический справочник `docs/shortcode-hint.md`**: единый источник текста подсказки для конструктора, экспортного файла и документации темы; гейт `sync_to_theme.py check` (новый гейт 4) сверяет строку `VCC-SHORTCODE-HINT-v1` во всех трёх репозиториях/местах.

## [0.7.2] — 2026-09-20

- **Smart-подсказка шорткодов при вводе**: под текстовыми полями (markdown/textarea) появляется кнопка «Справка по шорткодам Виты»; как только в тексте появляется `[vita_…]`, кнопка подсвечивается. Раскрытие — таблица всех 10 тегов темы (сверены с контроллером vita_theme.php 1.10.1) с примерами, назначением и правилом «не вкладывать внутрь [vita_html]».
- **Моки шапки/подвала магазина — точная копия Виты**: разметка повторяет header_topbar/header_main/footer.twig классами темы (.mp-header-top, .mp-header, .tech-footer), стили взяты из vita.css без приближений (топбар 12px/шесть, поиск 44px, кнопка «Каталог» 44×44, контейнер 1640px, футер-сетка auto-fit и отступы 3.5rem/2rem), темные значения — из [data-theme="dark"] темы.
- **Фуллскрин как демка Виты**: предпросмотр на всю страницу — это теперь настоящая страница магазина: секции лендинга тянутся на всю ширину окна, скроллится весь документ одним окном браузера (внутренних скролл-контейнеров и лишней полосы прокрутки справа нет), шапка конструктора — узкая фиксированная полоса сверху, на коротких страницах подвал магазина прилипает к низу окна.

## [0.7.1] — 2026-09-20

- **Подсказка у панели экспорта** (иконка «?» рядом с «Скачать»): как вставлять шорткоды Виты — текстовым блоком или через блок «HTML темы», — чтобы они пережили экспорт файла и импорт в модуль. Разворачивается по наведению и по фокусу с клавиатуры, на узких экранах скрывается вместе с текстами кнопок.

## [0.7.0] — 2026-09-20

Лендинг-секции: полноценные продающие страницы из статичных блоков — обложка, тарифы, шаги, отзывы, видео.

- **19 новых лендинг-блоков** (группа «Лендинг-секции»): обложка (Hero), бейджи доверия, преимущества, картинка + текст, шаги/таймлайн, цифры, отзывы, команда, документы, призыв (CTA), контакты, соцсети, чек-лист, разделитель, SEO-текст, тарифы, колонки текста, видео, логотипы партнёров. Каждый блок — полноширинная секция с выбором фона (как у страницы / приглушённый / карточка / фирменный / картинка / видео), отступов, ширины и якоря.
- **Кнопка-форма из текста**: `[текст](form:ID)` превращается в фирменную кнопку — рантайм темы открывает модалку формы магазина (тот же приём, что у соглашений `agree:`).
- **Акцент `==текст==`** — выделение слов фирменным цветом прямо в заголовках и абзацах.
- **Блок «Видео»**: вставьте обычную ссылку YouTube/Vimeo/Rutube/OK/Dailymotion/VK или готовый iframe-код из «Встроить» — конструктор извлечёт адрес плеера, а тема соберёт безопасный iframe на витрине (в файле экспорта iframe/script не появляются никогда).
- **Блок «HTML темы»** (`[vita_html]…[/vita_html]`) — клапан для точечной вёрстки, которой нет в каталоге блоков; содержимое проходит через штатный санитайзер темы.
- **Редактор повторяющихся элементов**: карточки с сортировкой и удалением для шагов, тарифов, отзывов и т.д.; редактор вкладок теперь тот же механизм.
- Экспортный CSS дополнен каркасом секций и всеми блоками на токенах `--mp-*`; классы vcc-v1 не менялись — эволюция аддитивная. Требуется тема 1.10.1+ этой же ветки (рантайм собирает фоны/иконки/видео/якоря и кнопки `form:`).

## [0.6.0] — 2026-09-20

Шапка как пульт: три главных действия всегда под рукой, страница — на всю ширину одним кликом.

- **Переключатель темы** стал компактным (иконки солнца/луны вместо текстовых кнопок) — то же место, втрое меньше места.
- **Кнопка «Загрузить пресет»** прямо в шапке: без пресета — призыв к действию, после загрузки показывает имя палитры («Палитра: Магазин») и подсвечивается акцентом. Клик открывает онбординг с дропзоной — сменить палитру можно в любой момент.
- **«На весь экран»**: сгенерированная страница разворачивается на всю ширину окна без палитры и шапки конструктора — только некликабельные шапка/подвал Виты и сам контент, как на витрине. Возврат — кнопкой «Вернуться в редактирование» или Esc.
- **Убрано пустое место справа**: рабочая область центрируется на широких экранах, пусто поровну по бокам вместо перекоса вправо.
- Шапка не переполняется на узких окнах: второстепенные подписи прячутся, остаются иконки.

## [0.5.0] — 2026-09-20

Шорткоды всех контентных модулей темы — конструктор собирает лендинги из живых блоков магазина.

- **Три новых блока-шорткода**: «Визуальные блоки» (`[vita_visual id]` — слайдер/баннер/LookBook), «Универсальные блоки товаров» (`[vita_all_in_one id]`), «Стена категорий и брендов» (`[vita_extra_wall id]`). В экспорт идёт литеральный шорткод — на витрине рендерит живой модуль темы со всеми своими настройками.
- **Каталог пресета расширен**: тема 1.10.1+ отдаёт в `catalog` списки инстансов этих модулей (имя + статус) — пикеры выбирают блок из реальных данных, выключенные помечены в списке. Старые пресеты — ручной ввод ID, как раньше.
- Требуется тема с поддержкой шорткодов (1.10.1+ с обновлением модификатора).

## [0.4.1] — 2026-09-20

- **Шапка и подвал магазина в редакторе**: канвас всегда показывается в контексте страницы — сверху и снизу некликабельные моки шапки/подвала Виты на палитре магазина (раньше контекст был только в режиме предпросмотра).
- README: прямая ссылка на онлайн-версию (GitHub Pages) в шапке документа.
## [0.4.0] — 2026-09-20

Пикеры модулей магазина: ID подставляются из реальных данных, угадывать не нужно.

- **Каталог модулей в пресете**: экспорт пресета в «Дизайне и стилях» (тема) несёт поле `catalog` — реальные FAQ-группы (название, число вопросов) и формы магазина. Конструктор заполняет ими выпадающие списки блоков-шорткодов; подписи моков показывают человеческие имена («Гарантия и возврат» вместо «группа #2»).
- **Совместимость в обе стороны**: старые пресеты без каталога — поля остаются ручным вводом ID с подсказкой; старые конструкторы поле `catalog` игнорируют.
- Каталог переживает перезагрузку браузера (localStorage).

## [0.3.0] — 2026-09-20

Первый экран по обратной связи владельца: весь инструмент виден сразу.

- **Полный редактор открыт сразу**, поверх — модалка онбординга: принцип работы в три шага, загрузка пресета палитры, готовые макеты. Закрытие кнопкой, кликом по фону или Esc; «домик» в шапке возвращает справку. У вернувшегося пользователя с черновиком модалка сама не открывается.
- **Блок «Спойлер» удалён** — FAQ-аккордеоны только живым шорткодом `[vita_faq]`: вопросы и ответы ведутся в админке магазина, а не в контенте. Классы `.vcc-spoiler` в экспортных стилях сохранены — у живых магазинов уже есть контент на этом CSS.
- **Палитра блоков в один ряд** (как в конструкторе-эталоне), группа «Медиа» слита в «Блоки контента».
- **Без нейрослоп-бордеров**: цветные левые полосы цитат и врезок заменены мягкой тенью-парением, у врезок — цветная метка сверху. Экспортные стили синхронизированы с темой (один файл в двух репозиториях, гейт сборки).
- Тёмный режим теперь красит и сам интерфейс конструктора, а не только контент.

## [0.2.0] — 2026-09-20

Синхронизация с темой Vita 1.10.1: конструктор и модуль «Универсальные блоки контента» работают как единая система.

- **Блоки-шорткоды `[vita_faq]` и `[vita_form]`** (новая группа «Модули магазина»): живые модули магазина прямо в контенте. В редакторе — некликабельный мок-плейсхолдер с бейджем; в экспорт идёт только литеральный шорткод в обёртке `vcc-shortcode` — движок темы заменяет его на витрине, моки в файл и буфер не попадают никогда. FAQ: ID группы (0 — все активные) и опциональный заголовок; Форма: ID обязателен, без него блок не экспортируется.
- **Палитра магазина по контракту 1.10.1**: принимается каноничный экспорт кнопки «Экспорт пресета для Конструктора» (`type: vita-theme-preset`, поле `name`) и, для совместимости, ранние экспорты (`schema: vita-theme-preset-v1`).
- **Галерея макетов** на первом экране: «Статья-гид», «Страница FAQ», «Обзор товара» — превью карточек рендерятся настоящим экспортным рендером (WYSIWYG), автоматически перекрашиваются загруженной палитрой магазина.
- **Публикация**: репозиторий открыт (`Tom-Opencart/vita-content-constructor`), сайт живёт на GitHub Pages; кнопка «Открыть конструктор» в теме и документация ведут сюда.
- Санитизация на стороне темы проверена против реального экспорта: обёртка, литеральные шорткоды и `data-vcc-*` проходят без потерь, `onclick`/`javascript:`/`<script>` вырезаются.
- Мелкие правки, улучшения и исправления.

## [0.1.0] — 2026-09-19

Первый релиз (M0–M3).

- **12 типов блоков**: заголовки H2–H4, текст с мини-markdown (жирный, курсив, код, ссылки, соглашения `[текст](agree:ID)`), списки, цитаты, врезки (info/success/warning/danger), спойлеры, табы, таблицы, картинки, оглавление.
- **Предпросмотр в контексте магазина**: мок шапки и подвала с некликабельными тестовыми данными, светлая и тёмная темы на тех же токенах, что ставит тема.
- **Палитра только из токенов**: цвета блоков — имена `--mp-*` с фолбэками; произвольный hex в модели отсутствует физически; загрузка пресета магазина (`vita-preset.json`) перекрашивает всё приложение.
- **Экспорт vcc-v1**: HTML с маркером контракта, JSON-бэкап проекта, CSS на токенах (`css/export.css` — единственный источник, вшивается в приложение: превью = экспорт байт-в-байт).
- **Импорт**: JSON проекта, пресет темы; автосохранение в localStorage, undo/redo.
- Мини-markdown безопасен: HTML во входе экранируется, URL-схемы фильтруются.
