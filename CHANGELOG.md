# Changelog

Все заметные изменения Вита — Конструктора контента.

## [0.9.9] — 2026-09-22

- **Таймлайн «Шаги» — современная версия**: градиентная линия с растворением
  к концу, точки с halo-обводкой (масштабируются при наведении на карточку),
  карточки с крупным радиусом 16px и двухслойной мягкой тенью, при hover —
  акцентная рамка `--mp-primary` и усиленная тень, год-подпись — капс с
  разрядкой. Тёмная тема: тени слабее, токены прежние.

## [0.9.8] — 2026-09-22

- **Блок «Логотипы партнёров»**: при центрированном заголовке секции ряд
  логотипов теперь центрируется (раньше знаки липли к левому краю широкого
  контейнера при пустом правом поле).
- **Logo-заглушка перерисована**: прежняя пиктограмма читалась как
  «тумблер»; новая — скруглённая плашка-«знак бренда» (ромб + подписная
  линия) в палитре Виты, стилистически единая с hero-заглушкой. Копии
  конструктора и темы синхронны.

## [0.9.7] — 2026-09-22

- **Hero-заглушка без кнопки Play**: пиктограмма-кнопка, нарисованная в
  `vita-placeholder-hero.jpg`, при `background-size: cover` оказывалась
  ровно в центре hero и читалась как элемент видео/наслаивалась на текст.
  Заменена на универсальную пиктограмму «изображение» (плашка с горами
  и солнцем в палитре Виты) — она не спорит с контентом ни в предпросмотре,
  ни на витрине. Копии конструктора и темы синхронны, кеш-бастер `?v=`
  поднимается версией 0.9.7.

## [0.9.6] — 2026-09-22

- **Таймлайн «Шаги» приведён к макету Виты**: вертикальная линия и точки-
  маркеры теперь СЛЕВА от карточек (раньше линия была внутри карточек),
  карточки — белые с мягкой тенью и парением при наведении, точка —
  фирменный `--mp-primary` с обводкой фона страницы.
- **Новое поле «Подпись»** в шагах (например, год «2024») — маленькая
  жирная строка в цвет бренда над названием шага, как на референсе.
- Тёмная тема: обводка точки берёт тёмный фон страницы, карточка —
  тёмную поверхность токена `--mp-card-bg`.

## [0.9.5] — 2026-09-22

- **Кеш-бастер превью-заглушек**: локальные копии `assets/placeholders/*`
  получают суффикс `?v=<версия>` — обновлённая заглушка после деплоя Pages
  показывается сразу, без устаревшей картинки из дискового кеша браузера.
- **Копии заглушек синхронизированы с темой** (md5-идентичны
  `upload/image/catalog/vita-placeholder-*` из темы): превью конструктора
  рисует ту же стилистическую заглушку, что придёт в магазин с архивом.
## [0.9.4] — 2026-09-22

- **Переключатель темы и селектор ширины переехали в панель предпросмотра**:
  они управляют именно страницей (моки + контент), поэтому жили в шапке
  фуллскрина, а не в редакторе. В шапке редактора остались только действия
  над проектом (пресет, экспорт, Помощник, фуллскрин); тема/ширина — рядом
  с кнопкой «Вернуться в редактирование». Механика прежняя: тот же store
  (тема проекта / ширина контейнера), предпросмотр перерисовывается сразу.
## [0.9.3] — 2026-09-22

- **Штатные заглушки изображений вместо битых картинок**: путь по умолчанию
  у всех блоков с изображениями — файлы темы `image/catalog/vita-placeholder-*`
  (hero 1600×900, фото 800×800, логотип 480×240, стилистика Виты). Владелец
  один раз заменяет файл в Менеджере изображений магазина — все блоки, где
  путь не меняли, получают его картинку, контент править не нужно.
  Покрыты: фон hero/секций, «Картинка + текст», логотипы партнёров, аватары
  отзывов, фото команды, документы/сертификаты.
- **Предпросмотр без битых картинок**: в самом конструкторе (Pages) штатные
  заглушки рисуются из локальных копий `assets/placeholders/` — пути
  `image/catalog/...` существуют только в магазине.

## [0.9.2] — 2026-09-22

- **Новый блок-спец-метка «Отзыв о магазине»** (`[vita_testimonial]`): живые
  отзывы витрины (vita_comment, статус=1) вместо статичных текстов. Пикер
  по каталогу пресета (конкретный отзыв) либо счётчик «первые N последних»
  с опцией случайного порядка; атрибуты id/count/random темы поддержаны
  полностью. Секционные поля (фон/заголовок/отступы) — как у остальных
  блоков-спец-меток.
- **Каталог пресета дополнен разделом `testimonials`**: экспорт пресета из
  темы теперь несёт и отзывы (id, автор·город, рейтинг, статус); старые
  пресеты поле не несут — блок даёт ручной ввод ID, ничего не ломается.
- **Подсказка статичного блока «Отзывы (текстовые)»** перенаправляет к живым
  отзывам: статичные тексты — для лендингов, витрина магазина — спец-меткой.
- **Промт Помощника ужат вдвое** (25.3 → 12.9 КБ): реестр больше не
  повторяет 11 подсекционных полей для каждого из 35 блоков — один указатель
  на `sec`, состав документирован в «Общих полях секции» один раз.

## [0.9.1] — 2026-09-22

- **Название модуля синхронизировано с темой**: «Универсальные HTML блоки
  контента» — в мета-описании, текстах онбординга и подсказке экспортной

## [0.9.0] — 2026-09-22

- **Один файл — «Скачал / Загрузил»**. Меню «Файл» с пятью пунктами
  удалено; в шапке одна экспортная кнопка — акцентная **«Скачать для
  магазина»** (тот же `content-*.html` для кнопки «Импорт из Конструктора»).
  «Скачать проект JSON» и «Скачать CSS» убраны вовсе: черновик конструктор
  сохраняет сам (автосохранение в браузере), а стили никогда не скачиваются —
  стилизация контента живёт в обоих репозиториях (конструктор и тема) и
  правится синхронно, что бы ни экспортировал конструктор, тема уже умеет
  это показывать. Undo остался на Ctrl+Z.
- **Два режима на первом экране** — онбординг открывается выбором:
  карточки «Собрать самому» (полный редактор) и «Собрать по образцу сайта»
  (визард). Загрузка палитры — одна компактная строка «необязательно»,
  галерея макетов и открытие сохранённой страницы — ниже.
- **Визард «Собрать страницу по образцу» ведёт сам**: три шага без терминов
  JSON/HTML/CSS, новый шаг мягко проявляется анимацией, фокус сразу на
  первом поле. Скопировали задание — шаг 2 сам перестраивается: галочка
  «задание скопировано», блок-подсказка «вставьте его в чат нейросети» с
  кнопкой «Нейросеть ответила — дальше»; возврат — «Изменить ссылку» и
  «Повторить шаг 2». Невалидный ответ нейросети объясняется по-человечески
  и не стирает вставленный текст; пустой список блоков ловится отдельно.
- Онбординг: убран дублировавшийся вводный абзац, восстановлен скрытый input
  открытия файла (пропал в незавершённой правке), исправлен дисбаланс тегов
  в подсказке визарда.

## [0.8.6] — 2026-09-21

- **Авторелиз по тегу**: пуш аннотированного тега `v*` запускает CI
  (сборка + оба смоука + гейт бандла) и создаёт GitHub Release с заметками
  из соответствующего раздела CHANGELOG.md — ручной `gh release create`
  больше не нужен. Нет раздела в CHANGELOG — релиз не создаётся, джоба
  красная: тег без changelog не пройдёт молча.
- Утилита `release.yml` идемпотентна: существующий релиз не трогает
  (перевыпуск тега безопасен).

## [0.8.5] — 2026-09-21

- **Автодеплой подтверждён и защищён CI**: Pages (legacy из main) пересобирает
  витрину на каждый пуш автоматически — ноль ручных шагов; перед этим CI
  (`.github/workflows/ci.yml`) гоняет сборку, оба смоука и гейт «js/app.js
  закоммичен вместе с src/» — сломанный или забытый бандл ловится на CI,
  а не на витрине.
- **Шапка выровнена пиксель-в-пиксель**: бренд 230px с правым бордером,
  продолжающим линию границы сайдбара (левый паддинг шапки 20px — правая
  грань бренда и колонки совпадают, без ступеньки 2px). Бордер на токене
  `--mp-border-color` — корректен в тёмной теме (#3D3844), нейтральный
  `#eee`-нейрослоп не вернётся.

## [0.8.4] — 2026-09-21

- **Умная подсказка типов в Помощнике** — три слоя вместо одного:
  посимвольное расстояние (Дамерау—Левенштейн) по type и label, транслит
  («tarifs» → pricing, «otzyvy» → reviews) и слово-матч по русским label

  vita_faq, «seo текст» → seotext). При равном штрафе побеждает большее
  покрытие точными словами. Кривая настроена на 55 кейсах, все закодированы
  в смоук v0.8.0 (53 матча) — регрессия ловится сборкой. Было: «о компании»
  подсказывала alert.
- **Шапка без мусора**: бренд «Вита · Конструктор» шириной ровно с левую
  колонку (250px) и всегда в одну строку — раньше переносился на две
  в узких окнах; убрана подпись content.html — не несла информации:
  имя файла задаёт slug при экспорте. На ≤900px (палитра складывается
  над канвасом) фикс-ширина бренда снимается.

## [0.8.2] — 2026-09-21

- **Секционные поля у блоков-шорткодов** (`vita_faq`, `vita_form`, `vita_html`,
  `vita_all_in_one` и прочие спец-метки): в панели блока появились `sec`-настройки
  (фон, отступы, якорь, заголовок) — как у обычных секций. Экспорт оборачивает
  шорткод в `vcc-section` (якорь/заголовок/фон), старые проекты без `sec`
  экспортируются голым шорткодом — обратная совместимость сохранена. Паспорт
  Помощника и schema.ts (контракт vcc-v1) актуализированы.

## [0.8.1] — 2026-09-21

- **Переключатель ширины сайта в шапке конструктора** (compact 1210 / optimal 1400 /
  wide 1640 / fluid 100% — та же таблица, что в vars_css.php темы): предпросмотр,
  моки шапки/подвала и превью карточек живут на одном `--vita-container-max`.
  Значение приходит из пресета (`theme_vita_container_width`) и подстраивается
  селектом вручную; выбор сохраняется между сессиями (`vcc_container_width_v1`).
- **Моки шапки/подвала — только в предпросмотре**: канвас редактора показывает
  только карточки блоков; контекст магазина (шапка и подвал Виты) — в фуллскрине
  «На весь экран», где и решается, как страница выглядит на витрине.

## [0.8.0] — 2026-09-21

- **Помощник «Создать по донору»** — конструктор остаётся статическим (без сети,
  ключей и чтения чужих сайтов), весь веб-интеллект на стороне AI, которого выбирает
  пользователь. Цикл: ссылка на страницу-образец → конструктор собирает промт со
  строгим реестром своих блоков → пользователь скармливает его любому AI с доступом
  в веб (ChatGPT, Claude, DeepSeek) → ответ вставляется обратно → черновик лендинга
  собирается в канвасе (undo-чекпойнт ставится, палитра магазина не перезаписывается).
- **Паспорт возможностей генерируется из живого реестра** (`src/core/passport.js`):
  документ не пишется руками и не устаревает — собирается при загрузке из `BlockRegistry`.
  Человекочитаемый дамп `docs/CONSTRUCTOR-PASSPORT.md` — он же живая документация
  и вход для ручного сценария «вставить паспорт в AI»; гейт сборки падает при
  рассинхроне документа и бандла (`node tools/dump_passport.js` обновляет).
- **Приёмник ответа с мягкой починкой**: срез markdown-забора ```json…```, извлечение
  JSON из текста с пояснениями, починка висячих запятых, оборачивание массива блоков
  и ответа без обёртки в каркас проекта; unknown-типы дают человеческую ошибку с
  подсказкой ближайшего блока (расстояние Дамерау—Левенштейна по type и русскому
  label, плюс транслитерация: «tarifs» → «pricing»), >20 блоков — предупреждение.
- **Точки входа**: карточка «Создать по донору (AI)» на первом экране (под галереей
  макетов) и кнопка «Помощник» в шапке редактора. Копирование — Clipboard API на HTTPS
  с fallback на execCommand для file://, плюс «Скачать .txt».
- Смоук `tests/smoke_v080.js`: паспорт покрывает 34 типа, промт ≤ 25 КБ с донором,
  пожеланиями и строгим форматом; 11 сценариев починки ответа; полный конвейер
  «ответ AI → нормализация → штатный импорт»; гейт паспорта.
- **Единый источник версии**: `tokens.js` больше не дублирует версию — читает
  билдерную `window.VCC_APP_VERSION` (фолбэк — для запуска модулей вне бандла:
  смоуки, дампер паспорта). Подъём `APP_VERSION` в `build/build.py` теперь
  доезжает до экспорта и паспорта без второй правки.

Технические термины контракта (`div.vcc-shortcode`, `VCC-SHORTCODE-HINT-v1`) не менялись — обратная совместимость полная.

## [0.7.4] — 2026-09-20

- **Чек-лист перед экспортом**: если в проекте нет ни одного блока группы «Модули магазина», при нажатии «Скачать» появляется мягкое напоминание (инфо-тост, экспорт не блокируется): живые модули — слайдер, FAQ, форма, товары — добавляются блоками из палитры. ## [0.7.3] — 2026-09-20

- **Подсказка о спец-метках вшита в экспортный файл**: каждый скачанный HTML теперь несёт комментарий с каноническим текстом (виден при открытии файла в любом редакторе; при импорте в модуль санитайзер темы снимает комментарий — контент не замусоривается).
- **Канонический справочник `docs/shortcode-hint.md`**: единый источник текста подсказки для конструктора, экспортного файла и документации темы; гейт `sync_to_theme.py check` (новый гейт 4) сверяет строку `VCC-SHORTCODE-HINT-v1` во всех трёх репозиториях/местах.

## [0.7.2] — 2026-09-20

- **Smart-подсказка шорткодов при вводе**: под текстовыми полями (markdown/textarea) появляется кнопка «Справка по шорткодам Виты»; как только в тексте появляется `[vita_…]`, кнопка подсвечивается. Раскрытие — таблица всех 10 тегов темы (сверены с контроллером vita_theme.php 1.10.1) с примерами, назначением и правилом «не вкладывать внутрь [vita_html]».
- **Моки шапки/подвала магазина — точная копия Виты**: разметка повторяет header_topbar/header_main/footer.twig классами темы (.mp-header-top, .mp-header, .tech-footer), стили взяты из vita.css без приближений (топбар 12px/шесть, поиск 44px, кнопка «Каталог» 44×44, контейнер 1640px, футер-сетка auto-fit и отступы 3.5rem/2rem), темные значения — из [data-theme="dark"] темы.
- **Фуллскрин как демка Виты**: предпросмотр на всю страницу — это теперь настоящая страница магазина: секции лендинга тянутся на всю ширину окна, скроллится весь документ одним окном браузера (внутренних скролл-контейнеров и лишней полосы прокрутки справа нет), шапка конструктора — узкая фиксированная полоса сверху, на коротких страницах подвал магазина прилипает к низу окна.

Разворачивается по наведению и по фокусу с клавиатуры, на узких экранах скрывается вместе с текстами кнопок.

## [0.7.0] — 2026-09-20

Лендинг-секции: полноценные продающие страницы из статичных блоков — обложка, тарифы, шаги, отзывы, видео.

- **19 новых лендинг-блоков** (группа «Лендинг-секции»): обложка (Hero), бейджи доверия, преимущества, картинка + текст, шаги/таймлайн, цифры, отзывы, команда, документы, призыв (CTA), контакты, соцсети, чек-лист, разделитель, SEO-текст, тарифы, колонки текста, видео, логотипы партнёров. Каждый блок — полноширинная секция с выбором фона (как у страницы / приглушённый / карточка / фирменный / картинка / видео), отступов, ширины и якоря.
- **Кнопка-форма из текста**: `[текст](form:ID)` превращается в фирменную кнопку — рантайм темы открывает модалку формы магазина (тот же приём, что у соглашений `agree:`).
- **Акцент `==текст==`** — выделение слов фирменным цветом прямо в заголовках и абзацах.
- **Блок «Видео»**: вставьте обычную ссылку YouTube/Vimeo/Rutube/OK/Dailymotion/VK или готовый iframe-код из «Встроить» — конструктор извлечёт адрес плеера, а тема соберёт безопасный iframe на витрине (в файле экспорта iframe/script не появляются никогда).
- **Блок «HTML темы»** (`[vita_html]…[/vita_html]`) — клапан для точечной вёрстки, которой нет в каталоге блоков; содержимое проходит через штатный санитайзер темы.
- **Редактор повторяющихся элементов**: карточки с сортировкой и удалением для шагов, тарифов, отзывов и т.д.; редактор вкладок теперь тот же механизм.
- Экспортный CSS дополнен каркасом секций и всеми блоками на токенах `--mp-*`; классы vcc-v1 не менялись — эволюция аддитивная. Требуется тема 1.10.1+ этой же ветки (рантайм собирает фоны/иконки/видео/якоря и кнопки `form:`).

## [0.6.0] — 2026-09-20

Шапка как пульт: три главных действия всегда под рукой, страница — на всю ширину одним кликом.

- **Переключатель темы** стал компактным (иконки солнца/луны вместо текстовых кнопок) — то же место, втрое меньше места.
- **Кнопка «Загрузить пресет»** прямо в шапке: без пресета — призыв к действию, после загрузки показывает имя палитры («Палитра: Магазин») и подсвечивается акцентом. Клик открывает онбординг с дропзоной — сменить палитру можно в любой момент.
- **«На весь экран»**: сгенерированная страница разворачивается на всю ширину окна без палитры и шапки конструктора — только некликабельные шапка/подвал Виты и сам контент, как на витрине. Возврат — кнопкой «Вернуться в редактирование» или Esc.
- **Убрано пустое место справа**: рабочая область центрируется на широких экранах, пусто поровну по бокам вместо перекоса вправо.
- Шапка не переполняется на узких окнах: второстепенные подписи прячутся, остаются иконки.

## [0.2.0] — 2026-09-20

Синхронизация с темой Vita 1.10.1: конструктор и модуль «Универсальные блоки контента» работают как единая система.

- **Блоки-шорткоды `[vita_faq]` и `[vita_form]`** (новая группа «Модули магазина»): живые модули магазина прямо в контенте. В редакторе — некликабельный мок-плейсхолдер с бейджем; в экспорт идёт только литеральный шорткод в обёртке `vcc-shortcode` — движок темы заменяет его на витрине, моки в файл и буфер не попадают никогда. FAQ: ID группы (0 — все активные) и опциональный заголовок; Форма: ID обязателен, без него блок не экспортируется.
- **Палитра магазина по контракту 1.10.1**: принимается каноничный экспорт кнопки «Экспорт пресета для Конструктора» (`type: vita-theme-preset`, поле `name`) и, для совместимости, ранние экспорты (`schema: vita-theme-preset-v1`).
- **Галерея макетов** на первом экране: «Статья-гид», «Страница FAQ», «Обзор товара» — превью карточек рендерятся настоящим экспортным рендером (WYSIWYG), автоматически перекрашиваются загруженной палитрой магазина.
- **Публикация**: репозиторий открыт (`Tom-Opencart/vita-content-constructor`), сайт живёт на GitHub Pages; кнопка «Открыть конструктор» в теме и документация ведут сюда.
- Санитизация на стороне темы проверена против реального экспорта: обёртка, литеральные шорткоды и `data-vcc-*` проходят без потерь, `onclick`/`javascript:`/`<script>` вырезаются.
- Мелкие правки, улучшения и исправления.
