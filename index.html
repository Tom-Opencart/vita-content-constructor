Вита · Конструктор Спец-метки модулей Виты — вставляйте текстовым блоком или через «HTML темы» Теги вида [vita_visual id=78], [vita_faq id=3], [vita_form id=5] переживают экспорт файла и импорт в модуль, а на витрине превращаются в живые блоки. В палитре есть и готовые блоки спец-меток с выбором ID из каталога магазина — они надёжнее ручного ввода.

Вита — Конструктор контента

Соберите страницу для магазина — описание товара, статью или посадочную — и перенесите её в модуль «Вита — Универсальные HTML блоки контента» одним файлом.

Загрузить палитру магазина (необязательно) — файл из админки: Расширения → Вита → Дизайн и стили → «Экспорт пресета для Конструктора»
Или начните с готового макета
Открыть сохранённую страницу файлом

Собрать страницу по образцу

Страница-образец, которая вам нравится, изучается нейросетью, которую выберете вы. Конструктор подготовит задание, вы его скопируете, вставите ответ — черновик соберётся сам.

1

Укажите страницу-образец

Его вы отдадите нейросети на следующем шаге
2

Поручите нейросети изучить образец

  1. Нажмите кнопку — задание скопируется в буфер обмена.
  2. Откройте нейросеть с доступом в интернет (ChatGPT, Claude, DeepSeek) и вставьте задание в чат.
  3. Когда она ответит — переходите к шагу 3.
Посмотреть задание
Задание скопировано

Вставьте его в чат нейросети — она изучит страницу-образец. Когда ответит, возвращайтесь сюда.

3

Вставьте ответ нейросети

Если конструктор ответил «это не ответ по заданию» — значит, нейросеть что-то объяснила вместо сборки страницы. Напишите ей: «Собери страницу строго по заданию, верни только данные страницы» — и вставьте её новый ответ сюда.
